# Assets

Here you will find assets referenced throughout the guides. They are all placed on a single page for your convenience.

### Base Resource & Data Pack
ZIP files containing the `pack.mcmeta` and directory structure for an addon in the form a resource and data pack.

**📦 Download (MC 1.20.1)**: [resources.zip](/content/resources.zip) and [data.zip](/content/data.zip)

### Standard Template (Blockbench)
A project file for Blockbench, to be used as the starting point for desinging backpack models.

**📦 Download**: [template.bbmodel](/content/template.bbmodel)

### Example Addon

An example of a complete Backpacked addon. Can be used for reference. The ZIP file needs to be extracted.

**📦 Download (MC 1.20.1)**: [example_addon.zip](/content/template.bbmodel)
