# Assets

Here you will find assets referenced throughout the guides. They are all placed on a single page for your convenience.

### Standard Template (Blockbench)
A project file for Blockbench, to be used as the starting point for desinging backpack models.

**📦 Download**: [template.bbmodel](/content/template.bbmodel)

### Base Addon Pack
A ZIP file containing the basic folder structure and the required `backpacked_addon.mcmeta` to create a Backpacked addon.

**📦 Download (MC 1.21.1)**: [base_addon.zip](/content/base_addon.zip)

### Example Addon Pack
An example of a completed Backpacked addon. Can be used for reference.

**📦 Download (MC 1.21.1)**: [example_addon.zip](/content/example_addon.zip)
