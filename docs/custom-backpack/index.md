# Custom Backpacks

:::warning
This guide only applies to Backpacked 3.0 and above. Custom backpacks are not supported in prior versions.
:::

Backpacked allows creators, including modpack and mod developers, to add new backpack cosmetics simply by using the combination of a data and resource pack. If you would like to learn how to add a new backpack, check out the [Getting Started](custom-backpack/getting-started) section.
